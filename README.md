# daymark

Минималистичный календарь-трекер в одном HTML-файле. Тапаешь по дню — он закрашивается. Тапаешь ещё раз — спрашивает, убрать ли отметку. Всё.

> ⚠️ **Это полный вайбкод.** Весь код написан Claude. Я его не писал построчно, не ревьюил и не гарантирую, что внутри всё красиво и правильно. Работает у меня — и ладно. Если что-то сломалось, issues и PR приветствуются, но ожидания держите разумными.

## Что умеет

- Бесконечная лента месяцев: 12 месяцев назад и вперёд от текущего (и дальше назад, если есть старые отметки)
- Тап по дню — отметить, повторный тап — убрать (с подтверждением)
- Выбор акцентного цвета отметок
- Светлая и тёмная тема (по умолчанию — как в системе, переключается вручную)
- Неделя начинается с понедельника, интерфейс на русском
- Стиль в духе iOS: размытая шапка, safe-area, без выделения текста
- Данные хранятся локально в браузере (`localStorage`, ключ `marked-days-v1`) — никаких серверов и аккаунтов
- Без зависимостей, без сборки, один файл

## Как запустить

**Локально:** просто открой `calendar.html` в браузере.


## Ограничения

- Данные живут только в `localStorage` конкретного браузера и устройства. Очистил данные сайта — отметки пропали. Синхронизации между устройствами нет.
- Экспорта/импорта пока нет.
- Отметка — просто «да/нет», без заметок и категорий.
